A LITTLE GUIDANCE

From edit to live.

Your quick guide to keeping the website fresh.

01 / ACCESS

Your own secure login

Use the GitHub account invited to manage this website. The dashboard overview is public; the editor requires authorization before you can change anything.

Open editor
02 / EDIT

Keep the details current

Choose a content section in the sidebar. Each editor contains only the fields for that component. Update the fields you need. Add only confirmed services, prices, and opening hours.

Use a country code for the dialing number, such as +13477215261.

03 / PUBLISH

Put your changes online

Click Publish in the editor. This saves your content and starts a website rebuild. The live page changes only after that deployment succeeds.

Check the public website
04 / NEED HELP?

Something not showing?

Refresh the public website after a few minutes. If your update still isn’t visible, ask your website manager to check the deployment. Don’t share your password.

The editor handles content and photos. Contact your website manager for new pages or layout changes.
